# Hoàn thành các Task T034, T035, T036

Các thay đổi sau đã được thực hiện để hoàn thành các chức năng sinh câu hỏi và quản lý Job.

## T034: Create question generation job API
- Đã thêm cột `config` (JSON) vào database schema cho model `Job` (tại `backend/app/models/material.py`).
- Cập nhật Pydantic schema `JobResponse` (tại `backend/app/schemas/material_schema.py`) để cho phép hiển thị thuộc tính `config`.
- Cập nhật `question_generation_service.py` và route `POST /material/{material_id}/generate-questions` (tại `backend/app/api/routes/jobs.py`) để nhận và lưu lại payload cấu hình (bao gồm: `query`, `number_of_questions`, `difficulty`, `bloom_level`, `language`, `top_k`) vào field `config` của object `Job`.

## T035: Run generation job API
- Quá trình chạy background để sinh câu hỏi hiện tại đã hoạt động trong file `backend/app/workers/question_worker.py`. Worker sử dụng LLM và RAG để retrieve các đoạn material, và lưu câu hỏi (`Question`) cùng với `options` và `source_chunk_ids`.
- Đã cập nhật model `Question` (tại `backend/app/models/question.py`) để thêm trường khóa ngoại `job_id` liên kết đến `Job`.
- Đã chỉnh sửa `process_question_generation_job` trong worker để gán `job_id` cho mỗi đối tượng `Question` trước khi lưu. Các câu hỏi giờ đây đã được gắn vĩnh viễn với Job đã sinh ra chúng.

## T036: List generated questions API
- Đã thêm API route `GET /jobs/{job_id}/questions` (tại `backend/app/api/routes/jobs.py`) để trả về danh sách các câu hỏi vừa được sinh ra.
- API này kiểm tra trạng thái Job và trả về List of `QuestionResponse`. Cấu trúc trả về bao gồm nội dung câu hỏi, độ khó, bloom_level, explanation, options và mảng các source chunks mà model đã sử dụng.
- Cập nhật schema `QuestionResponse` (tại `backend/app/schemas/question_schema.py`) thêm thuộc tính `job_id`.

---
*Lưu ý: Các thay đổi database được thực hiện trên Model SQLAlchemy. Hãy đảm bảo chạy công cụ Alembic migration ở môi trường thật (Docker/Local) trước khi restart backend service.*
